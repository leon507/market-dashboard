# A股市场全景看板

每日自动更新的A股市场数据看板，包含主要指数行情、行业板块资金流向和热点资讯。

## 功能

- **7大指数概览**：上证指数、深证成指、沪深300、中证500、中证1000、创业板指、科创50
- **近1月走势图**：可点击切换各指数的30天K线走势
- **对比数据**：较昨日、较上周同期、较上月同期涨跌幅
- **行业板块资金流向**：行业涨幅榜、主力资金净流入、概念板块涨幅榜
- **热点资讯**：30条最新市场快讯

## 自动更新

GitHub Actions 每个交易日（周一至周五）北京时间 15:30 自动拉取最新数据并更新页面。

## 数据来源

- 实时行情：腾讯证券 API
- K线数据：腾讯证券 API
- 板块排名：东方财富 API
- 热点资讯：东方财富快讯 API

## 技术栈

- Python 3 (数据获取与HTML生成)
- Chart.js (走势图渲染)
- GitHub Actions (定时任务)
- GitHub Pages (静态网站托管)
